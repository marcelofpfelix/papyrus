## Status meanings

- `Verified`: implemented and checked with the listed evidence.
- `Partial`: some code or docs exist, but the requested behavior is incomplete.
- `Missing`: no meaningful implementation exists yet.
- `Unverified`: code or docs may exist, but current evidence is too weak.
- `Deferred`: explicitly postponed by Marcelo.
